# GameMVP

シンプルな2DブラウザゲームのMVP。プレイヤーを操作してコインを集め、時間内のスコアを競う。

## 遊び方

`index.html` をブラウザで開くだけで動作する(ビルド不要)。

- 矢印キー / WASD: 移動
- コインに触れるとスコア+10
- 制限時間30秒、時間切れでゲーム終了、ボタンでリスタート

## ファイル構成

- `index.html` — マークアップ
- `style.css` — 見た目
- `game-logic.js` — 描画に依存しないゲームロジック(移動・当たり判定・スコア)
- `main.js` — 描画・入力・ゲームループ(Canvas 2D)
- `game-logic.test.js` — ロジックのテスト

## テスト

```
npm test
```

Node.js 標準のテストランナー(`node --test`)を使うため、依存パッケージのインストールは不要。
